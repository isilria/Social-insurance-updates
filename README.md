# 사회보험 재원별 대사 보조 도우미

## 다운로드

[최신 정식판과 변경 내역](https://github.com/isilria/Social-insurance-updates/releases/latest)에서 실행 파일과 Windows ZIP을 받을 수 있습니다. Windows와 Microsoft Excel이 필요합니다.

## 배포 파일

- [`latest.ini`](latest.ini)는 자동 업데이트에 사용하는 버전, 다운로드 주소, SHA-256을 담고 있습니다.
- 서식과 라이브러리를 포함한 전체 소스는 릴리스의 `SocialInsurance_Ver<버전>_Source.zip` 첨부에서 받을 수 있습니다.
