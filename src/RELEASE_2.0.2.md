# 사회보험 재원별 대사 보조 도우미 2.0.2

2026-09-04 정식 배포 / @ 살구아빠

## 이번 변경

- 결재자료 및 반환·추징 PDF: 약 150dpi JPEG에서 약 600dpi RGB 무손실 압축으로 개선.
- A4 크기와 기존 페이지 배치를 유지하며 가로·세로 픽셀 수를 각각 4배 확대.
- 화면 및 자동 업데이트 기준 버전을 2.0.2로 통일.
- 공개 배포용 내장 검증 서식에서 직원·급여 예시 데이터를 제거. 사용자가 입력한 실제 자료는 포함하지 않음.

기존 2.0.2 테스트 버전의 보정 풍선창, 고지금액 적용, 확인완료 후 반환·추징 명단 유지, 실제 제출서 생성 기능은 유지합니다.
PDF는 고해상도 이미지 방식입니다. 텍스트 검색용 벡터 PDF는 아닙니다.
이전에 만든 PDF는 바뀌지 않으므로 이 버전으로 다시 생성해 주세요.

## 실행

Windows 10/11 및 .NET Framework 4.8 환경에서 실행파일을 엽니다.
제출서 생성에는 설치된 Microsoft Excel이 필요합니다.
프로그램 종료 시 검증 결과 엑셀을 자동 저장하거나 저장 여부를 묻지 않습니다.
필요한 저장/출력은 종료 전에 해당 버튼으로 직접 수행하세요.

## 소스 및 빌드

Source.zip을 풀고 Windows PowerShell에서 build_Ver2.0.ps1을 실행합니다.
별도 다운로드 없이 포함된 dependencies, templates, assets를 사용합니다.

- InsurancePayrollValidator_Ver2.0.cs: 입력·대사·엑셀/PDF 출력·기본 UI
- TestFeatures202.cs: 2.0.2 화면 연결 및 제출 생성 흐름
- ManualContributions202.cs: 개인부담금 수기 보정 및 확인 처리
- PrintQuality202.cs: 약 600dpi 이미지 및 PDF용 무손실 압축
- templates: 개인정보를 비운 배포용 서식
- dependencies: 기존 앱에서 사용하는 EPPlus 라이브러리
- assets: 프로그램 아이콘

설정 저장 폴더의 기존 이름에 '테스트'가 남아 있는 것은 기존 사용자 설정을 유지하기 위한 호환성 조치입니다.
소스 압축에는 실제 급여자료, 보험 원본, 검증용 결과, 개인 설정, 인증정보를 넣지 않습니다.

## 확인 항목

- 두 방향 A4 PDF 생성, 페이지 이미지 크기·무손실 스트림 검증 및 화면 렌더링 확인.
- 고지금액 적용·저장·재로딩, 확인완료 후 반환/추징 명단 및 출력 유지.
- 공무원 재원 선택, 확인 목록 유지, 원본 파일 및 종료 시 저장 여부 확인.
- 교육공무직·계약제교원 제출서 각각 xlsx 생성 및 재열기.
